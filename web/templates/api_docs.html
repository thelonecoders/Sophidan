📚 Academic Research Suite — API Reference

← Back to dashboard

Every endpoint below is served from the local Flask + Socket.IO server. The base URL is http://127.0.0.1:8765 unless you overrode the port with --port.

All responses are JSON. Endpoints that accept a body expect Content-Type: application/json.

Scraping

Async scraping tasks with live WebSocket progress.

POST /api/scraping/search Submit a scrape task → returns task_id

Request body

  "query": "transformer architecture",
  "sources": ["arxiv", "semantic_scholar"],
  "max_results": 50,
  "filters": {"year_min": 2017}
}

{"task_id": "a1b2c3…", "status": "queued"}

WebSocket

Real-time event streams via Socket.IO at the root namespace.

GET /ws/status Socket.IO subsystem status
WS connect / disconnect
WS subscribe

Client → Server

{"task_id": "a1b2c3…"}
# or
{"channel": "logs"}
WS unsubscribe
WS scrape:progress / scrape:complete / scrape:error Server → Client broadcasts

Example event

{
  "task_id": "a1b2c3…",
  "progress": 0.45,
  "message": "Fetched 22/50 results"
}
